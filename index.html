📄 ResumeMatch — Resume–Job Match Scorer

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A TF-IDF + cosine similarity model trained on 12 job descriptions and 12 sample resumes (486 words) scores how well a resume fits a job post. Matched pairs score 0.51 on average vs 0.06 for wrong pairs — a 9.0x gap — and the model picks the right job for a resume 12/12 times.

How it works: both texts are turned into TF-IDF vectors (rare, meaningful words weigh more than common ones), then the cosine similarity between the two vectors is the match score. The page also checks a list of 58 job skills and shows which ones the resume already has and which ones the job asks for but the resume is missing. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model.

Try it: Asha Verma’s Data Analyst resume against the Data Analyst job scores about 44%. The same resume against the DevOps Engineer job scores about 2% — and the page lists all 8 DevOps skills as missing. A resume with no real content scores near 0% against any job.
